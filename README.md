# Обедающие философы
Философы сидят за круглым столом, думают и едят. Для еды каждому нужны две соседние вилки. В этой программе используется последовательная модель, философы хранятся в массиве и программа по очереди обрабатывает события.
Чтобы избежать взаимной блокировки, программа выдаёт сразу обе вилки. Голодные философы встают в очередь и получают вилки в порядке поступления заявки, те в порядке очереди (FIFO). Если первый в очереди пока не может поесть, остальные ждут.

## Сборка и запуск

Нужны компилятор C, CMake версии 3.16 или выше и Make. Команды выполняются из корня проекта:

```bash
cmake -S . -B build -DBUILD_TESTING=ON
cmake --build build
./bin/philosophers
```

По дефолту программа запускает 5 философов, каждый должен поесть 3 раза. 
Справка:

```bash
./bin/philosophers --help
```

## Параметры

```text
./bin/philosophers [N] [cycles] [think_min] [think_max] [eat_min] [eat_max]
                  [max_wait] [display_delay] [seed] [strategy] [time_limit]
```

Аргументы задаются по порядку. Последние можно не указывать — тогда используются значения по умолчанию.

| Аргумент | Что задаёт | По дефолту |
|---|---|---:|
| N | Количество философов и вилок, минимум 2 | 5 |
| cycles | Сколько раз должен поесть каждый философ, минимум 1 | 3 |
| think_min, think_max | Диапазон времени размышления в миллисекундах | 500, 1500 |
| eat_min, eat_max | Диапазон времени еды в миллисекундах | 400, 1000 |
| max_wait | Максимальное ожидание вилок в миллисекундах | 5000 |
| display_delay | Реальная пауза между моментами событий, 0 — без пауз | 120 |
| seed | Начальное значение генератора случайных чисел | 42 |
| strategy | Способ выдачи вилок, поддерживается только fifo | fifo |
| time_limit | Общий лимит модельного времени, без лимита - 0 | 60000 |

Все числа должны быть неотрицательными и помещаться в `int`. Время еды и `max_wait` должны быть больше нуля. Слишком большие сочетания параметров, которые могут привести к переполнению времени или статистики, программа отлавливает и отклоняет.

Модельное время и реальное время отличаются. Программа сразу переходит к ближайшему событию. `display_delay` нужен только для удобного просмотра и не меняет результат. При одинаковых параметрах и `seed` вывод повторяется.

Например, быстрый запуск без пауз:

```bash
./bin/philosophers 5 3 500 1500 400 1000 5000 0 42
```

Простой пример с двумя философами:

```bash
./bin/philosophers 2 1 3 3 7 7 7 0 42
```

Оба думают 3 ms, затем едят по очереди по 7 ms. Всё заканчивается на 17-й миллисекунде модельного времени.

## Вывод и завершение

Программа показывает события, состояния философов и владельцев вилок. В конце выводит число завершённых циклов и статистику ожидания. Весь вывод также записывается в `philosophers.log` в текущем каталоге. Следующий запуск перезапишет этот файл.

Ожидание ровно `max_wait` разрешено. Если оно становится больше, модель останавливается. Общий лимит тоже завершает работу, но если все философы успели закончить ровно на его границе, это считается успехом. Остановить программу вручную можно через Ctrl+C. При остановке она освобождает вилки и выводит итоги, прерванная еда не считается завершённым циклом.

| Код выхода | Значение |
|---:|---|
| 0 | Все циклы выполнены или показана справка |
| 1 | Ошибка параметров или работы с выводом |
| 2 | Превышен лимит ожидания или достигнут общий лимит |
| 130 | Остановка по SIGINT, обычно Ctrl+C |
| 143 | Остановка по SIGTERM |

## Тесты

```bash
ctest --test-dir build --output-on-failure
```

Можно запустить их и напрямую:

```bash
./bin/philosophers_tests ./bin/philosophers
```

В `tests/test_philosophers.c` девять групп проверок: справка, простой запуск, несколько циклов, лимит ожидания, общий лимит, неправильные параметры, сигналы SIGINT/SIGTERM, запуск со 137 философами и порядок очереди. 
Проверяются также повторяемость результата, совпадение вывода с логом, выдача вилок и их освобождение. Для каждого запуска создаётся временный каталог, поэтому тесты не перезаписывают лог в корне проекта. Ошибки проверяются через `SOFT_ASSERT_ERR`.

## Что где лежит

- `src/philosophers.c` - запуск программы.
- `src/parameters.c` - чтение аргументов и справка.
- `src/simulation.c` - философы, вилки, очередь и обработка событий.
- `src/console.c` - вывод, лог, сигналы и паузы.
- `inc/` - заголовочные файлы.
- `tests/` - тесты и примеры вывода.
- `REPORT.md` - описание решения и результаты проверок.
- `build/` - файлы сборки, `bin/` - программа и тесты.
